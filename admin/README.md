# Admin Dashboard - AdilQadri E-Commerce

The Admin application is an internal ERP and management dashboard built with React and Vite. It connects to the same backend API as the storefront but requires administrative privileges to access its routes.

## Features
- **Dashboard Analytics**: High-level overview of revenue, orders, and customer acquisition.
- **Inventory Management**: Interface to Create, Read, Update, and Delete (CRUD) products and manage variants.
- **Order Fulfillment**: Track, view, and update customer order statuses.

## Running Locally
Ensure the Backend API is running on Port 5000 first, then:

```bash
npm install
npm run dev
```
The application will usually start on `http://localhost:5174`.
